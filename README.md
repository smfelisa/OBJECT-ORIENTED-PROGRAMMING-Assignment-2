# OBJECT-ORIENTED-PROGRAMMING-Assignment-2
Student name: Felisa Chin Sze Min &amp; Nurul Jannah Binti Mohd Azrin

This assignment is the extend of the Student Management System developed in Assignment 1, using Java OOP concepts. The system will manage student details, student status, registration, course information and tuition fee calculation. The aim of this assignment is to show the application of the OOP concepts of encapsulation, inheritance, polymorphism, method overriding, constructors and control structures in a Java program.
